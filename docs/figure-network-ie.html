Phonological correspondences · Paper 2 · exp. 2

Indo-European draws itself as a point cloud

Each point is a language. Its position comes only from how its consonants correspond to every other language's — the mean number of phonological features that differ, pair by pair. No family tree, no reconstruction, and the branch colours were added last, only to check the picture. The contiguity is not imposed; it emerges.

Distance = mean count of differing panphon features per aligned consonant slot, over statistically detected coderivative sets (LexStat); layout by classical MDS. Solid links join a language to its 3 nearest neighbours within the same branch; dashed links are nearest neighbours in a different branch — almost always areal contact (Albanian→Romanian, Balkan; Romani→Romanian) or a creole beside its lexifier. Genealogy lives in the distribution; the label is only a coarse summary of this geometry. Data: network_*_ie.csv.
